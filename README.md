# SelfWebsite

A personal portfolio website built with Next.js, TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Notes

- Content is stored in `src/data/*` so it can be updated without rewriting page components.
- PDF assets live in `public/` and are linked from `src/data/profile.ts`.
- Deployment steps are documented in `DEPLOYMENT.md`.
- Public reference deployment: `https://selfwebsite-ten.vercel.app/`
